# Dasara Developers

Next.js marketing site for Dasara Developers, with **Dasara Utsav** as the flagship 4BHK villa community in Chikkatirupathi.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Vercel project root is this folder (`dasara-web`).
